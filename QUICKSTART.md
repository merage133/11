## 🚀 Запуск

```bash

ollama serve

# 2. Запустите сервер
node server.cjs

# 3. Откройте браузер
http://localhost:3001
```

```bash

```

## 🎤 Голосовой ввод

### В основном чате
1. Нажмите кнопку 🎤
2. Разрешите доступ к микрофону
3. Говорите
4. Нажмите Enter

### В CODER
1. Откройте CODER
2. Нажмите кнопку 🎤
3. Говорите какой код написать
4. Нажмите Enter

## 💻 CODER

### Поддерживаемые языки
- **Веб**: JavaScript, TypeScript, HTML, CSS
- **Компилируемые**: Python, C++, C#, Java, Go, Rust

### Автоматическое исправление
- Включено по умолчанию
- AI проверяет код, находит ошибки, исправляет
- Повторяет до 3 попыток
- Можно отключить переключателем

### Пример использования
1. Откройте CODER
2. Скажите или напишите: "Напиши программу на Python для расчёта факториала"
3. AI напишет код
4. Нажмите "Запустить"
5. Если есть ошибка - AI исправит автоматически

## 🐛 Решение проблем

### AI отвечает на другом языке
- Перезапустите сервер
- Проверьте что используется правильная модель

### Код не компилируется
- Установите соответствующий компилятор
- Проверьте что компилятор в PATH
- Увеличьте таймаут в настройках

### Голосовой ввод не работает
- Используйте Chrome или Edge
- Разрешите доступ к микрофону
- Проверьте что микрофон работает

### Сервер не запускается
- Проверьте что порт 3001 свободен
- Проверьте что Node.js установлен
- Проверьте логи в консоли

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте документацию
2. Проверьте логи
3. Перезапустите сервер
4. Проверьте версию Node.js (должна быть 18+)
