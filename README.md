# 🇷🇺 RU AI Studio — AI с полным доступом к компьютеру

## Возможности

- 🎤 **Голосовой ввод** — говорите, AI слушает (Chrome/Edge)
- 🖥️ **Видит экран** — делает скриншоты через getDisplayMedia
- 📁 **Работает с файлами** — читает, пишет, листает папки
- ⚡ **Выполняет команды** — терминал, установка программ
- 🔌 **Управляет ПК** — выключение, перезагрузка
- 🌐 **Автоматизация браузера** — клики, ввод текста (puppeteer)
- 🔒 **Полностью приватно** — всё локально, без интернета
- ⚡ **Без цензуры** — выполняет любые запросы

## 🚀 Быстрый старт

### 1. Установите Node.js

Скачайте с https://nodejs.org/ (версия LTS)

### 2. Установите Ollama

Скачайте с https://ollama.com/download

### 3. Запустите установщик

Откройте командную строку в папке проекта:

```cmd
node installer.js
```

Установщик:
- ✅ Установит зависимости
- ✅ Соберёт проект
- ✅ Проверит Ollama
- ✅ Предложит установить модель
- ✅ Создаст ярлык на рабочем столе

### 4. Запустите

Дважды кликните на ярлык **RU AI Studio** на рабочем столе.

## 📦 Ручная установка

### 1. Установите зависимости

```cmd
npm install
```

### 2. Соберите проект

```cmd
npm run build
```

### 3. Загрузите модель

```cmd
ollama pull qwen2.5:7b
```

### 4. Запустите

**Вариант 1: Через скрипт**
```cmd
start.bat
```

**Вариант 2: Вручную**

Откройте **два** окна командной строки:

Окно 1 — Ollama:
```cmd
ollama serve
```

Окно 2 — Сервер:
```cmd
node server.cjs
```

Затем откройте: http://localhost:3001

## 🎤 Голос

Нажмите 🎤 в поле ввода и говорите. Работает в Chrome и Edge.
Поддерживает русский язык.

## 🖥️ Скриншоты

Нажмите 🖥️ (монитор) в поле ввода. Браузер попросит разрешение на захват экрана.
AI увидит скриншот и сможет его описать.

## ⚡ Системные команды

Для работы нужен запущенный `server.cjs`.

Примеры запросов:
- "Выключи компьютер через 30 секунд"
- "Покажи файлы на рабочем столе"
- "Создай файл test.txt с текстом hello"
- "Установи VS Code"
- "Какая у меня система?"

## 🌐 Автоматизация браузера

Для работы нужна дополнительная настройка:

```cmd
# 1. Установить puppeteer
npm install puppeteer

# 2. Запустить Chrome с отладкой
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
```

После этого AI сможет:
- Кликать по элементам
- Вводить текст в поля
- Переходить по страницам

## ❓ Проблемы

### Голос не работает
- Используйте Chrome или Edge
- Разрешите доступ к микрофону

### "Сервер не запущен"
- Запустите: `node server.cjs`

### Tool calling не работает
- Используйте модель qwen2.5:7b или llama3.1:8b
- Модели типа codellama не поддерживают tools

### Автоматизация браузера не работает
- Установите puppeteer: `npm install puppeteer`
- Запустите Chrome: `chrome --remote-debugging-port=9222`
