# 🇷🇺 RU AI Studio — Локальный AI-ассистент для кода

## Что это?

Готовая связка **Web UI + Нейросеть**, которая работает в России:
- ✅ **Без VPN** — не нужны иностранные сервисы
- ✅ **Бесплатно** — без токенов (Ollama) или с бесплатными токенами (GigaChat, YandexGPT)
- ✅ **Без ошибок 401/403/405** — всё локально или через российские сервисы
- ✅ **Работает с файлами** — прикрепляйте код из репозиториев
- ✅ **Один файл** — запускается из собранного `dist/index.html`

## 🚀 Быстрый старт (2 минуты)

### Шаг 1: Установите Ollama

**Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**Windows/macOS:**  
Скачайте с [ollama.com/download](https://ollama.com/download)

### Шаг 2: Загрузите модель для кода

```bash
ollama pull qwen2.5-coder:7b
```

Рекомендуемые модели:
| Модель | Размер | Описание |
|--------|--------|----------|
| `qwen2.5-coder:7b` | 4.7 GB | 🏆 Лучшая для кода |
| `deepseek-coder-v2:16b` | 8.9 GB | Мощная, но больше RAM |
| `codellama:7b` | 3.8 GB | Классика от Meta |
| `starcoder2:7b` | 4.0 GB | От HuggingFace |
| `qwen2.5-coder:1.5b` | 1.0 GB | Лёгкая, для слабых ПК |

### Шаг 3: Запустите Ollama

```bash
ollama serve
```

### Шаг 4: Откройте RU AI Studio

Просто откройте файл `dist/index.html` в браузере!

Или запустите локальный сервер:
```bash
npx serve dist
```

## 📁 Альтернативные провайдеры

### GigaChat (Сбер) — бесплатно 1000 запросов/день

1. Зарегистрируйтесь на [developers.sber.ru](https://developers.sber.ru/studio/workbench)
2. Создайте проект "GigaChat API"
3. Получите Authorization Key
4. Вставьте в настройки приложения

### YandexGPT (Яндекс) — бесплатный пробный период

1. Зарегистрируйтесь на [console.cloud.yandex.ru](https://console.cloud.yandex.ru/)
2. Создайте каталог и сервисный аккаунт
3. Получите IAM-токен: `yc iam create-token`
4. Вставьте в настройки приложения

```bash

```

Результат в папке `dist/` — это статические файлы, которые можно открыть в браузере.

## ❓ Частые проблемы

### "Не удалось подключиться"
- Убедитесь, что `ollama serve` запущена
- Проверьте, что URL `http://localhost:11434` доступен
- Попробуйте: `curl http://localhost:11434/api/tags`

### Медленные ответы
- Используйте модель поменьше: `qwen2.5-coder:1.5b`
- Уменьшите `max_tokens` в настройках
- Закройте другие приложения

### Нет ответа от модели
- Проверьте, что модель загружена: `ollama list`
- Перезапустите: `ollama serve`
