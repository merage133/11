# 🎭 Mirage AI — Локальный AI-ассистент

Локальный AI с полным доступом к вашему компьютеру. Работает оффлайн, без VPN, без цензуры.

## 🚀 Быстрый старт

### 1. Установите зависимости

```bash
npm install
```

### 2. Соберите проект

```bash
npm run build
```

### 3. Запустите

**Вариант 1: Через Mirage.exe (рекомендуется)**
- Создайте `Mirage.exe` (см. [CREATE_EXE_GUIDE.md](CREATE_EXE_GUIDE.md))
- Поместите на рабочий стол
- Двойной клик для запуска

**Вариант 2: Через скрипт**
```cmd
start.bat
```

**Вариант 3: Вручную**

Откройте **два** окна командной строки:

Окно 1 — Ollama:
```cmd
ollama serve
```

Окно 2 — Сервер:
```cmd
node server.cjs
```

Затем откройте: http://localhost:3001

## 📦 Установка Ollama

Скачайте с https://ollama.com/download

### Загрузите модель

```cmd
# Рекомендуемая (поддерживает инструменты)
ollama pull qwen2.5:7b

# Мощная (нужно 16 GB RAM)
ollama pull qwen2.5:14b

# Лёгкая (для слабых ПК)
ollama pull qwen2.5:3b
```

## 🎯 Возможности

### Основные
- 💬 **Чат с AI** — без ограничений и цензуры
- 🔍 **Поиск в интернете** — через SearXNG (Google + Bing + DuckDuckGo)
- 📚 **База знаний** — добавляйте ссылки для обучения AI
- 🖥️ **Скриншоты** — AI видит ваш экран
- 📁 **Работа с файлами** — чтение, запись, список файлов
- ⚡ **Выполнение команд** — терминал, установка программ
- 🔌 **Управление ПК** — выключение, перезагрузка
- 🌐 **Автоматизация браузера** — клики, ввод текста (puppeteer)
- 🔒 **Полная приватность** — всё локально, без интернета
- 🕐 **Текущее время** — знает который час и какая дата

### Инструменты AI

| Инструмент | Описание |
|------------|----------|
| `search_internet` | Поиск в интернете (SearXNG + Wikipedia + DuckDuckGo) |
| `get_current_time` | Текущее время и дата |
| `take_screenshot` | Скриншот экрана |
| `list_files` | Список файлов в папке |
| `read_file` | Прочитать файл |
| `write_file` | Записать файл |
| `run_command` | Выполнить команду |
| `shutdown_pc` | Выключить компьютер |
| `restart_pc` | Перезагрузить компьютер |
| `open_url` | Открыть URL в браузере |
| `browser_click` | Кликнуть на элемент |
| `browser_type` | Ввести текст в поле |
| `get_system_info` | Информация о системе |

Добавляйте ссылки на статьи, документацию, любые материалы:

AI автоматически ищет информацию когда нужно:

## 🐛 Решение проблем

### "Ollama не отвечает"
```cmd
# Запустите Ollama
ollama serve

# Проверьте подключение
curl http://localhost:11434/api/tags
```

### "Модель не найдена"
```cmd
# Установите модель
ollama pull qwen2.5:7b

# Проверьте список моделей
ollama list
```

### "Tool calling не работает"
Используйте модели с поддержкой tools:
- `qwen2.5:7b` ✅
- `llama3.1:8b` ✅
- `codellama` ❌ (не поддерживает)

### "Сервер не запускается"
```cmd
# Проверьте порт
netstat -ano | findstr :3001

# Убейте процесс
taskkill /F /PID <PID>

# Запустите снова
node server.cjs
```

### "Поиск не работает"
- Проверьте подключение к интернету
- Попробуйте запрос на английском
- Проверьте что server.cjs запущен
