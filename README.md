# 🇷🇺 RU AI Studio — Локальный AI без цензуры

## Что это?

Полностью **локальная** связка Web UI + нейросеть:
- ✅ **Без VPN** — работает в России
- ✅ **Без токенов** — Ollama полностью бесплатна
- ✅ **Без цензуры** — системный промпт без ограничений
- ✅ **Приватно** — все данные только на вашем ПК
- ✅ **Без ошибок 401/403/405** — нет внешних API
- ✅ **Стриминг** — мгновенная отзывчивость
- ✅ **Работа с файлами** — прикрепляйте код из репозиториев

## 🚀 Установка (2 минуты)

### 1. Установите Ollama

**Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**Windows/macOS:**  
Скачайте с [ollama.com/download](https://ollama.com/download)

### 2. Загрузите модель

```bash
ollama pull qwen2.5-coder:7b
```

### 3. Запустите

```bash
ollama serve
```

### 4. Откройте RU AI Studio

Откройте `dist/index.html` в браузере.

## 🔒 Приватность

- Все данные хранятся **только на вашем компьютере**
- Ничего не отправляется в интернет (после загрузки модели)
- Нет регистрации, нет токенов, нет внешних API
- История чатов в localStorage вашего браузера

## 🔧 Сборка

```bash
npm install
npm run build
```

Результат в `dist/` — статические файлы, открываются в браузере.

## ❓ Проблемы

### "Не подключено"
- Запустите: `ollama serve`
- Проверьте: `curl http://localhost:11434/api/tags`

### Медленные ответы
- Используйте модель поменьше: `qwen2.5-coder:1.5b`
- Нужна видеокарта NVIDIA для ускорения
