### 2. 🖥️ Десктопная версия (Electron)

#### Возможности
- ✅ Полный доступ к файловой системе
- ✅ Системные диалоги (выбор файлов/папок)
- ✅ Управление процессами

- ✅ Системная информация
- ✅ Нативные уведомления
- ✅ Управление окном
- ✅ Открытие внешних ссылок
- ✅ Автономная работа

#### API
- `dialog.openFile()` - выбор файла
- `dialog.openDirectory()` - выбор папки
- `dialog.saveFile()` - сохранение файла
- `fs.readFile()` - чтение файла
- `fs.writeFile()` - запись файла
- `fs.readdir()` - список файлов
- `fs.exists()` - проверка существования
- `fs.stat()` - информация о файле
- `process.spawn()` - запуск процесса
- `clipboard.read()` - чтение буфера
- `clipboard.write()` - запись в буфер
- `system.getInfo()` - системная информация
- `window.minimize()` - свернуть
- `window.maximize()` - развернуть
- `window.close()` - закрыть
- `notification.show()` - уведомление
- `shell.openExternal()` - открыть URL
- `shell.openPath()` - открыть папку
- `app.quit()` - выйти

## 🚀 Быстрый старт

### Веб-версия

```bash
# 1. Установите зависимости
npm install

# 2. Установите Ollama
# https://ollama.com/download

# 3. Загрузите модель
ollama pull qwen2.5:7b

# 4. Запустите сервер
node server.cjs

# 5. Откройте браузер
http://localhost:3001
```

### Десктопная версия

```bash
# 1. Установите Electron зависимости
npm install --save-dev electron electron-builder concurrently

# 2. Обновите package.json
copy package.electron.json package.json  # Windows
cp package.electron.json package.json    # Linux/Mac

# 3. Создайте иконки в папке build/

# 4. Запустите
npm run dev

# 5. Соберите установщик
npm run build:electron
```
