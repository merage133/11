RU AI Studio — Локальный AI-ассистент с полным доступом к компьютеру

Этот продукт использует:
- Ollama (https://ollama.com) — локальная нейросеть
- Web Speech API — распознавание речи
- getDisplayMedia API — захват экрана

Все данные обрабатываются локально на вашем компьютере.
Никакая информация не отправляется на внешние серверы.
