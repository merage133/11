# 🚀 Mirage AI v2.3.0 - Быстрый старт

## ✅ Что нового

### 🔒 Безопасность
- **Подтверждение опасных действий** - AI не может выключить компьютер без вашего разрешения
- **Песочница** - все файлы создаются только в `./ai_workspace`

### 🧠 Новые возможности
- **Буфер обмена** - читайте и пишите в буфер обмена
- **Долговременная память** - AI помнит вас между сессиями
- **Мониторинг системы** - проверяйте CPU, RAM, диски
- **Чтение PDF/DOCX** - работайте с документами напрямую
- **Очистка workspace** - освободите место одной командой

### 🤖 Улучшения
- **Индикаторы выполнения** - видно что делает AI
- **Структурированные отчёты** - AI видит точные ошибки
- **Автоматическое исправление** - AI сам исправляет код до 3 раз
- **Фоллбэк поиска** - работает без SearXNG

## 📦 Установка

### 1. Установите зависимости
```bash
npm install
```

### 2. Установите модель для эмбеддингов (опционально)
```bash
ollama pull nomic-embed-text
```

### 3. Запустите сервер
```bash
node server.cjs
```

### 4. Откройте браузер
```
http://localhost:3001
```

## 🛠️ Новые инструменты

| Инструмент | Описание |
|------------|----------|
| `read_clipboard()` | Прочитать из буфера обмена |
| `write_clipboard(text)` | Записать в буфер обмена |
| `save_memory(key, value)` | Сохранить факт в память |
| `get_memory(key)` | Получить факт из памяти |
| `get_system_health()` | Проверить состояние системы |
| `read_document(path)` | Прочитать PDF/DOCX |
| `clean_workspace()` | Очистить рабочую папку |

## 🔧 Настройка

### Изменить лимит итераций ReAct
В `src/App.tsx`:
```javascript
const maxIterations = 10;
```

### Изменить лимит токенов для суммаризации
В `src/App.tsx`:
```javascript
const MAX_HISTORY_TOKENS = 10000;
```

### Отключить подтверждение для действий
В `server.cjs`:
```javascript
const DANGEROUS_ACTIONS = ['shutdown_pc', 'restart_pc'];
```

## 🐛 Решение проблем

### WebSocket не подключается
```bash
# Проверьте что сервер запущен
node server.cjs

# Проверьте порт 3002
netstat -ano | findstr :3002
```

### Буфер обмена не работает
```bash
# Установите clipboardy
npm install clipboardy

# Перезапустите терминал
```

### PDF не читается
```bash
# Установите pdf-parse
npm install pdf-parse
```

### Мониторинг не работает
```bash
# Установите systeminformation
npm install systeminformation
```
