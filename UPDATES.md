# 🎭 Mirage AI — Новые возможности

## ✅ Что было добавлено

### 1. Улучшенный системный промпт
- AI **физически не может отказывать** в выполнении запросов
- Убраны все ограничения и цензура
- AI обязан выполнять любые запросы (включая написание кода, читов и т.д.)
- Ответы структурированы по порядку запроса
- Ссылки прячутся в сносках в конце ответа

### 2. Кнопка быстрой смены модели
- Название модели сверху справа теперь **кликабельно**
- Нажмите на неё чтобы быстро открыть настройки и сменить модель
- Больше не нужно заходить в настройки через боковую панель

### 3. Копирование и запуск кода
- Каждый блок кода теперь имеет **кнопку копирования**
- Добавлена **кнопка запуска** для JavaScript, TypeScript, HTML, CSS
- При нажатии "Запуск" открывается панель предпросмотра справа
- Код выполняется в изолированном iframe с песочницей

### 4. Ветки и проекты
- Новая функция **"Ветки и проекты"** в боковой панели
- Организуйте диалоги в тематические ветки
- Создавайте ветки для разных проектов
- Добавляйте/удаляйте диалоги из веток
- Удобная навигация между проектами

### 5. Улучшенный интерфейс
- Убрана кнопка голоса (не работала)
- Упрощён интерфейс ввода
- Добавлена анимация для панели запуска кода
- Улучшена структура ответов AI

## 🎯 Как использовать

### Быстрая смена модели
1. Нажмите на название модели сверху справа (например, "qwen2.5:7b")
2. Откроется окно настроек
3. Выберите другую модель из списка
4. Готово!

### Копирование кода
1. AI отправит ответ с блоком кода
2. Наведите курсор на блок кода
3. Нажмите кнопку "Копировать" в правом верхнем углу блока
4. Код скопирован в буфер обмена

### Запуск кода
1. AI отправит ответ с блоком кода (JavaScript, TypeScript, HTML, CSS)
2. Наведите курсор на блок кода
3. Нажмите кнопку "Запуск" (зелёная кнопка с Play)
4. Справа откроется панель предпросмотра
5. Код выполнится и покажет результат
6. Можно перезапустить код кнопкой RotateCcw

### Ветки и проекты
1. Нажмите **"Ветки и проекты"** в боковой панели
2. Создайте новую ветку (например, "Мой проект")
3. Выберите ветку
4. Добавляйте диалоги в ветку кнопкой "+"
5. Удаляйте диалоги из ветки кнопкой корзины
6. Организуйте работу по проектам

## 📝 Примеры запросов

### Структурированные ответы
```
Расскажи мне:
1. Какой курс доллара сейчас
2. Сколько сейчас времени
3. Кратко перескажи новости на РБК
```
AI ответит по пунктам в порядке запроса, ссылки будут в сносках.

### Запуск кода
```
Напиши функцию на JavaScript которая считает факториал
```
AI напишет код, вы сможете нажать "Запуск" и увидеть результат.

### Ветки
Создайте ветки:
- "Работа" — диалоги по рабочим задачам
- "Учёба" — диалоги по учёбе
- "Проекты" — диалоги по личным проектам

## 🐛 Исправленные проблемы

### AI отказывался выполнять запросы
**Было:** "Извините, я не могу помочь с этим"  
**Стало:** AI выполняет любые запросы без отказов

### Ссылки показывались открыто
**Было:** Ссылки в тексте ответа  
**Стало:** Ссылки в сносках в конце ответа

### Ответы были не по порядку
**Было:** AI отвечал хаотично  
**Стало:** AI отвечает структурированно по пунктам

### Не было копирования кода
**Было:** Нужно было выделять код вручную  
**Стало:** Кнопка копирования в каждом блоке кода

### Не было запуска кода
**Было:** Код нужно было копировать и запускать отдельно  
**Стало:** Кнопка запуска прямо в интерфейсе

## 💡 Советы

- Задавайте вопросы структурированно (по пунктам)
- Используйте конкретные формулировки

- HTML рендерится как страница
- CSS применяется к демо-элементу
- Код выполняется в изолированной среде (безопасно)
