- AI больше не показывает URL-ссылки в тексте ответа
- При поиске информации AI даёт ответ на основе найденных данных
- Убран `open_url` из системного промпта — сайты открываются только по явному запросу

- Кнопка микрофона 🎤 возвращена в интерфейс
- Распознавание речи работает в Chrome/Edge
- Промежуточный текст показывается в поле ввода
- Индикатор "Слушаю..." при активной записи

### 3. Создан CODER — отдельное окно для кода
- Новая кнопка **CODER** в боковой панели (выделена цветом)
- Открывается на весь экран с разделённым интерфейсом
- **Слева**: чат с AI для написания кода
- **Справа**: панель предпросмотра с запуском кода
- Поддержка JavaScript, TypeScript, HTML, CSS
- Кнопки копирования и запуска на каждом блоке кода
- Изолированная среда выполнения (iframe с песочницей)

## 🚀 Как использовать

### Голосовой ввод
1. Нажмите кнопку 🎤 в поле ввода
2. Разрешите доступ к микрофону
3. Говорите — текст появится в поле
4. Нажмите Enter для отправки

### CODER
1. Нажмите кнопку **CODER** в боковой панели
2. Опишите какой код написать
3. AI напишет код с блоками ```язык ... ```
4. Нажмите кнопку **Запуск** на блоке кода
5. Увидите результат справа в панели предпросмотра
6. Можно перезапустить код кнопкой RotateCcw

### Поиск информации
```
Какой курс доллара сегодня?
Какая погода в Москве?
Последние новости технологий
```
AI найдёт информацию и даст ответ без ссылок.
