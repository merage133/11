# 🤖 AI Agent - Автономный AI помощник

Десктопное приложение на Python с PyQt6, реализующее автономного AI-агента с циклом ReAct, голосовым вводом и расширенным набором инструментов.

## 🎯 Возможности

- ✅ **Автономный AI-агент** с циклом ReAct и автоисправлением кода
- ✅ **Голосовой ввод** через Vosk (локальное распознавание речи)
- ✅ **11 инструментов** для работы с файлами, командной строкой, интернетом
- ✅ **Песочница** для безопасного выполнения кода
- ✅ **Долговременная память** для сохранения данных между сессиями
- ✅ **Тёмная тема** интерфейса
- ✅ **Упаковка в EXE** для распространения

## 📋 Требования

- **Python 3.10+**
- **Ollama** (локальный LLM сервер)
- **Модель Ollama** (рекомендуется: `qwen2.5:7b` или `llama3.1:8b`)
- **Модель Vosk** (для голосового ввода, опционально)

## 🚀 Быстрый старт

### 1. Установка Python 3.10+

**Windows:**
```bash
# Скачайте с https://www.python.org/downloads/
# При установке отметьте "Add Python to PATH"
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install python3.10 python3.10-venv python3-pip
```

**macOS:**
```bash
brew install python@3.10
```

### 2. Установка Ollama

**Windows/macOS:**
```bash
# Скачайте с https://ollama.com/download
```

**Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### 3. Загрузка модели Ollama

```bash
# Запустите Ollama (если не запущена)
ollama serve

# В другом терминале загрузите модель
ollama pull qwen2.5:7b
```

### 4. Создание виртуального окружения

```bash
# Перейдите в папку проекта
cd ai_agent

# Создайте виртуальное окружение
python -m venv venv

# Активируйте его
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 5. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 6. (Опционально) Установка модели Vosk для голосового ввода

```bash
# Создайте папку для моделей
mkdir models
cd models

# Скачайте модель (выберите подходящую с https://alphacephei.com/vosk/models)
# Для русского языка:
wget https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
unzip vosk-model-small-ru-0.22.zip
rm vosk-model-small-ru-0.22.zip

cd ..
```

### 7. Запуск приложения

```bash
# Убедитесь что Ollama запущена
ollama serve

# В другом терминале запустите приложение
python main.py
```

## 📦 Сборка EXE файла

### 1. Установка PyInstaller

```bash
pip install pyinstaller
```

### 2. (Опционально) Создание иконки

Создайте файл `app_icon.ico` (Windows) или `app_icon.png` (Linux/Mac) размером 256x256 пикселей.

### 3. Сборка

```bash
# Сборка в папку (рекомендуется для отладки)
pyinstaller build_exe.spec

# Или сборка в один файл (больше размер, но удобнее для распространения)
# Отредактируйте build_exe.spec, закомментируйте COLLECT и раскомментируйте EXE с onefile
pyinstaller build_exe.spec
```

### 4. Готовый EXE

Найдите собранный файл в папке `dist/AIAgent/`:
- **Windows:** `dist/AIAgent/AIAgent.exe`
- **Linux:** `dist/AIAgent/AIAgent`
- **macOS:** `dist/AIAgent/AIAgent.app`

### 5. Распространение

Для распространения передайте пользователю:
- Папку `dist/AIAgent/` целиком
- Или один EXE файл (если собраны в onefile режиме)
- Папку `models/` с моделью Vosk (если голосовой ввод нужен)

**Важно:** Пользователю также нужна установленная Ollama с загруженной моделью.

## 🎮 Использование

### 1. Выбор модели

При запуске выберите модель из выпадающего списка в верхней панели.

### 2. Текстовый ввод

Введите задачу в поле ввода и нажмите "Отправить" или Enter.

### 3. Голосовой ввод

1. Нажмите кнопку "🎤 Записать"
2. Говорите в микрофон
3. Нажмите "⏹️ Остановить" или дождитесь автоматической остановки
4. Текст будет вставлен в поле ввода
5. Нажмите "Отправить"

### 4. Примеры задач

```
Напиши программу на Python которая выводит "Hello, World!"
Создай файл test.txt с текстом "Привет, мир!"
Какой курс доллара сегодня?
Какое сейчас время?
Посчитай 2 + 2 * 2
Покажи файлы в рабочей области
Какая погода в Москве?
```

## 🛠️ Инструменты

AI агент имеет доступ к следующим инструментам:

| Инструмент | Описание |
|------------|----------|
| `write_file` | Записать файл в рабочую область |
| `read_file` | Прочитать файл из рабочей области |
| `list_files` | Список файлов в директории |
| `run_command` | Выполнить команду в терминале |
| `search_internet` | Поиск в интернете через DuckDuckGo |
| `get_current_time` | Текущее время и дата |
| `calculate` | Вычислить математическое выражение |
| `save_memory` | Сохранить данные в память |
| `get_memory` | Получить данные из памяти |
| `get_system_info` | Информация о системе |
| `open_url` | Открыть URL в браузере |

## 🔒 Безопасность

### Песочница

Все файловые операции ограничены папкой `./agent_workspace`. AI не может:
- Читать/писать файлы за пределами рабочей области
- Использовать абсолютные пути
- Использовать `..` для выхода из рабочей области

### Таймауты

Все команды имеют таймаут 15 секунд. При превышении процесс принудительно завершается.

### Опасные команды

Заблокированы опасные команды:
- `rm -rf /`
- `format`
- `del /f /q`
- `mkfs`

## 🐛 Решение проблем

### Ollama не запущена

```bash
# Запустите Ollama
ollama serve
```

### Модель не найдена

```bash
# Загрузите модель
ollama pull qwen2.5:7b

# Проверьте список моделей
ollama list
```

### Голосовой ввод не работает

1. Проверьте что модель Vosk скачана и распакована в `models/vosk-model-small-ru-0.22/`
2. Проверьте что микрофон доступен
3. Проверьте логи в файле `ai_agent.log`

### Ошибки при сборке EXE

```bash
# Очистите кэш PyInstaller
rm -rf build dist

# Переустановите PyInstaller
pip uninstall pyinstaller
pip install pyinstaller

# Попробуйте собрать снова
pyinstaller build_exe.spec
```

### EXE не запускается

1. Проверьте что Ollama запущена
2. Проверьте что модель загружена
3. Проверьте логи в файле `ai_agent.log` рядом с EXE
