# 📖 RU AI Studio — Инструкция для Windows

## 🚀 Быстрый старт (5 минут)

### Шаг 1: Установка Node.js

1. Скачайте Node.js LTS с официального сайта: https://nodejs.org/
2. Запустите установщик
3. Следуйте инструкциям (все галочки по умолчанию)
4. После установки перезапустите командную строку

**Проверка установки:**
Откройте командную строку (Win+R → cmd) и введите:
```cmd
node --version
```
Должно показать версию, например: `v20.11.0`

---

### Шаг 2: Установка Ollama

1. Скачайте Ollama с официального сайта: https://ollama.com/download
2. Запустите установщик `OllamaSetup.exe`
3. Следуйте инструкциям
4. После установки Ollama запустится автоматически

**Проверка установки:**
Откройте командную строку и введите:
```cmd
ollama --version
```
Должно показать версию, например: `ollama version 0.1.27`

---

### Шаг 3: Запуск установщика

1. Откройте командную строку (Win+R → cmd)
2. Перейдите в папку проекта:
```cmd
cd C:\путь\к\проекту\ru-ai-studio
```
3. Запустите установщик:
```cmd
node installer.js
```

**Что сделает установщик:**
- ✅ Проверит Node.js
- ✅ Установит npm зависимости
- ✅ Соберёт проект
- ✅ Проверит Ollama
- ✅ Предложит установить модель
- ✅ Создаст ярлык на рабочем столе
- ✅ Проверит работоспособность

---

### Шаг 4: Запуск

**Вариант 1: Через ярлык (рекомендуется)**
- Найдите на рабочем столе файл `RU AI Studio.bat`
- Дважды кликните по нему
- Браузер откроется автоматически

**Вариант 2: Через скрипт**
Откройте командную строку в папке проекта и введите:
```cmd
start.bat
```

**Вариант 3: Вручную**
Откройте **два** окна командной строки:

**Окно 1 — Ollama:**
```cmd
ollama serve
```

**Окно 2 — Сервер:**
```cmd
cd C:\путь\к\проекту\ru-ai-studio
node server.cjs
```

Затем откройте браузер: http://localhost:3001

## 📦 Установка модели

### Рекомендуемые модели

| Модель | Размер | Tool Calling | Описание |
|--------|--------|:---:|----------|
| `qwen2.5:7b` | 4.7 GB | ✅ | 🏆 Лучшая, поддерживает инструменты |

| `mistral:7b` | 4.1 GB | ✅ | Хорошая альтернатива |

### Установка модели через командную строку

Откройте командную строку и введите:

**Базовая модель (рекомендуется):**
```cmd
ollama pull qwen2.5:7b
```

**Мощная модель (нужно 16 GB RAM):**
```cmd
ollama pull qwen2.5:14b
```

**Лёгкая модель (для слабых ПК):**
```cmd
ollama pull qwen2.5:3b
```

### Проверка установленных моделей

```cmd
ollama list
```

## 🎤 Голосовой ввод

### Требования
- **Браузер:** Chrome или Edge (Firefox не поддерживает)
- **Микрофон:** должен быть подключён и работать

### Использование
1. Откройте RU AI Studio в браузере
2. Нажмите кнопку 🎤 в поле ввода
3. Разрешите доступ к микрофону
4. Говорите — текст появится в поле ввода
5. Нажмите Enter для отправки

### Проблемы
- **Не работает в Firefox** — используйте Chrome или Edge
- **Нет доступа к микрофону** — нажмите на иконку замка в адресной строке и разрешите микрофон
- **Плохое распознавание** — говорите чётко, без фонового шума

---

## 🖥️ Скриншоты

### Использование
1. Нажмите кнопку 🖥️ (монитор) в поле ввода
2. Выберите "Весь экран" или "Окно приложения"
3. AI увидит скриншот и сможет его описать

### Проблемы
- **Не показывает окно выбора** — проверьте разрешения в браузере
- **Чёрный экран** — некоторые приложения защищают контент (Netflix, банки)

## 🛠️ Системные команды

Для работы системных команд (файлы, команды, выключение) нужен запущенный сервер:

```cmd
node server.cjs
```

### Доступные команды

| Команда | Описание |
|---------|----------|
| "Покажи файлы на рабочем столе" | Список файлов |
| "Прочитай файл test.txt" | Чтение файла |
| "Создай файл hello.txt с текстом 'Привет'" | Запись файла |
| "Выполни команду dir" | Выполнение команды |
| "Выключи компьютер через 30 секунд" | Выключение ПК |
| "Перезагрузи компьютер" | Перезагрузка ПК |
| "Какая у меня система?" | Информация о системе |

### Проблемы
- **"Сервер не запущен"** — запустите `node server.cjs`
- **"Порт 3001 занят"** — закройте другой сервер или измените PORT в server.cjs

## ⚙️ Настройка

### Изменение порта сервера

Откройте `server.cjs` и измените:
```javascript
const PORT = 3001; // Измените на другой порт
```

### Изменение URL Ollama

1. Откройте настройки (⚙️)
2. В поле "URL Ollama сервера" укажите новый адрес
3. Например: `http://192.168.1.100:11434` для удалённого сервера

### Изменение системного промпта

1. Откройте настройки (⚙️)
2. Перейдите на вкладку "Параметры"
3. Измените текст в поле "Системный промпт"

## 🐛 Решение проблем

### "Node.js не найден"
- Переустановите Node.js с https://nodejs.org/
- Перезапустите командную строку после установки
- Проверьте PATH: `echo %PATH%`

### "Ollama не отвечает"
```cmd
:: Запустите Ollama
ollama serve

:: Проверьте подключение
curl http://localhost:11434/api/tags
```

### "Модель не найдена"
```cmd
:: Установите модель
ollama pull qwen2.5:7b

:: Проверьте список моделей
ollama list
```

### "Tool calling не работает"
Используйте модели с поддержкой tools:
- `qwen2.5:7b` ✅
- `llama3.1:8b` ✅
- `codellama` ❌ (не поддерживает)

### "Сервер не запускается"
```cmd
:: Проверьте порт
netstat -ano | findstr :3001

:: Убейте процесс
taskkill /F /PID <PID>

:: Запустите снова
node server.cjs
```

### "Голос не работает"
- Используйте Chrome или Edge
- Разрешите доступ к микрофону в браузере
- Проверьте что микрофон работает в системе

### "Ярлык не работает"
- Удалите старый ярлык
- Запустите установщик снова: `node installer.js`
- Или используйте `start.bat` напрямую
