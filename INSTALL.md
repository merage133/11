# 📖 RU AI Studio — Полная инструкция

## 🚀 Быстрый старт (5 минут)

### Шаг 1: Установка Node.js

**Windows/macOS:**
- Скачайте с https://nodejs.org/ (версия LTS)
- Установите, следуя инструкциям

**Linux (Ubuntu/Debian):**
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

**Linux (Fedora/RHEL):**
```bash
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo yum install -y nodejs
```

### Шаг 2: Установка Ollama

**Windows/macOS:**
- Скачайте с https://ollama.com/download
- Установите программу

**Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### Шаг 3: Запуск установщика

Откройте терминал в папке проекта и выполните:

```bash
node installer.js
```

Установщик:
- ✅ Проверит Node.js
- ✅ Установит зависимости
- ✅ Соберёт проект
- ✅ Проверит Ollama
- ✅ Предложит установить модель
- ✅ Создаст ярлык на рабочем столе

### Шаг 4: Запуск

**Вариант 1: Через ярлык**
- Найдите на рабочем столе файл `RU AI Studio` (Windows) или `ru-ai-studio.sh` (Linux)
- Дважды кликните

**Вариант 2: Через скрипт**
```bash
# Windows
start.bat

# Linux/macOS
chmod +x start.sh
./start.sh
```

**Вариант 3: Вручную**
```bash
# Терминал 1: Запуск Ollama
ollama serve

# Терминал 2: Запуск сервера
node server.js

# Терминал 3: Открыть браузер
# Windows:
start http://localhost:3001
# Linux:
xdg-open http://localhost:3001
# macOS:
open http://localhost:3001
```

## 📦 Установка модели

### Рекомендуемые модели

| Модель | Размер | Tool Calling | Описание |
|--------|--------|:---:|----------|
| `qwen2.5:7b` | 4.7 GB | ✅ | 🏆 Лучшая, поддерживает инструменты |
| `qwen2.5:14b` | 8.9 GB | ✅ | Мощнее, больше RAM |
| `llama3.1:8b` | 4.7 GB | ✅ | От Meta, хорошая |
| `mistral:7b` | 4.1 GB | ✅ | Хорошая альтернатива |
| `qwen2.5-coder:7b` | 4.7 GB | ❌ | Для кода, без tools |

### Установка модели

```bash
# Базовая модель (рекомендуется)
ollama pull qwen2.5:7b

# Мощная модель (нужно 16 GB RAM)
ollama pull qwen2.5:14b

# Лёгкая модель (для слабых ПК)
ollama pull qwen2.5:3b
```

### Смена модели в интерфейсе

1. Откройте настройки (кнопка ⚙️)
2. Перейдите на вкладку "Подключение"
3. В выпадающем списке "Модель" выберите нужную
4. Если модели нет в списке — установите её через `ollama pull`

## 🎤 Голосовой ввод

### Требования
- Chrome или Edge (Firefox не поддерживает)
- Разрешение на использование микрофона

### Использование
1. Нажмите кнопку 🎤 в поле ввода
2. Разрешите доступ к микрофону
3. Говорите — текст появится в поле ввода
4. Нажмите Enter для отправки

### Проблемы
- **Не работает в Firefox** — используйте Chrome/Edge
- **Нет доступа к микрофону** — разрешите в настройках браузера
- **Плохое распознавание** — говорите чётко, без шума

## 🖥️ Скриншоты

### Использование
1. Нажмите кнопку 🖥️ (монитор) в поле ввода

## 🐛 Решение проблем

### "Ollama не отвечает"

**Причина:** Ollama не запущена или недоступна

**Решение:**
```bash
# Запустите Ollama
ollama serve

# Проверьте подключение
curl http://localhost:11434/api/tags
```

### "Модель не найдена"

**Причина:** Модель не установлена

**Решение:**
```bash
# Установите модель
ollama pull qwen2.5:7b

# Проверьте список моделей
ollama list
```

### "Tool calling не работает"

**Причина:** Модель не поддерживает инструменты

**Решение:**
- Используйте `qwen2.5:7b` или `llama3.1:8b`
- Модели типа `codellama` не поддерживают tools

### "Сервер не запускается"

**Причина:** Порт занят или ошибка в коде

**Решение:**
```bash
# Проверьте порт
netstat -ano | findstr :3001  # Windows
lsof -i :3001                 # Linux/Mac

# Убейте процесс
taskkill /F /PID <PID>        # Windows
kill -9 <PID>                 # Linux/Mac

# Запустите снова
node server.js
```

### "Голос не работает"

**Причина:** Браузер не поддерживает или нет разрешения

**Решение:**
- Используйте Chrome или Edge
- Разрешите доступ к микрофону в настройках браузера
- Проверьте что микрофон работает в системе

### "Медленные ответы"

**Причина:** Слабый ПК или большая модель

**Решение:**
- Используйте модель поменьше: `qwen2.5:3b`
- Закройте другие приложения
- Добавьте больше RAM (если возможно)
- Используйте видеокарту NVIDIA для ускорения
