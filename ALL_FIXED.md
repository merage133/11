## Новые инструменты

### get_exchange_rate(from, to)
Получить курс валют
```
get_exchange_rate("USD", "RUB") → "Курс: 83.55"
```

### get_weather(city)
Получить погоду
```
get_weather("Москва") → "Температура: 15°C, облачно"
```

### search_internet(query)
Обычный поиск (автоматически определяет курс и погоду)
```
search_internet("курс доллара") → автоматически вызывает get_exchange_rate
search_internet("погода в Москве") → автоматически вызывает get_weather
```

### compile_and_run(code, language)
Компиляция и выполнение кода (используется автоматически)
```
compile_and_run("print('Hello')", "python") → "Hello"
```

## Решение проблем

### Поиск не работает
- Перезапустите сервер: `node server.cjs`
- Проверьте подключение к интернету
- Проверьте что используется модель с поддержкой tool calling

### Код не проверяется автоматически
- Убедитесь что модель поддерживает tool calling (qwen2.5:7b, llama3.1:8b)
- Перезапустите сервер
- Проверьте логи в консоли

### Курс валют не находится
- Проверьте подключение к интернету
- Попробуйте другой формат: "курс USD к RUB"

### Погода не находится
- Проверьте название города
- Попробуйте на английском: "Moscow" вместо "Москва"
