## Установка компиляторов

### Автоматическая установка
```cmd
node installer.js
```
Выберите компиляторы для установки.

### Ручная установка

**Все компиляторы одной командой:**

**Windows:**
```powershell
winget install Python.Python.3.12 MSYS2.MSYS2 Microsoft.DotNet.SDK.8 EclipseAdoptium.Temurin.21.JDK GoLang.Go Rustlang.Rust
```

**Linux:**
```bash
sudo apt-get update
sudo apt-get install -y python3 build-essential mono-complete default-jdk golang
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

**macOS:**
```bash
brew install python gcc mono openjdk go rustup
```

## Решение проблем

### Поиск не работает
- Перезапустите сервер
- Проверьте подключение к интернету
- Проверьте что используется правильная модель

### Код не запускается
- Проверьте что компилятор установлен
- Проверьте что сервер запущен
- Посмотрите ошибку - там будет инструкция по установке

### Python не работает
```cmd
# Проверьте установку
python --version

# Если не установлен
winget install Python.Python.3.12
```

### Автоматическое исправление не работает
- Проверьте что переключатель "Автоисправление" включён
- Проверьте что сервер запущен
- Попробуйте исправить код вручную
