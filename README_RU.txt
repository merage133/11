ЧТО ЭТО?
--------
Локальный AI-ассистент с полным доступом к компьютеру.
Работает оффлайн, без VPN, без цензуры.

ТРЕБОВАНИЯ
----------
1. Node.js (https://nodejs.org/)
2. Ollama (https://ollama.com/download)
3. Модель: qwen2.5:7b (установить: ollama pull qwen2.5:7b)

КАК ЗАПУСТИТЬ
-------------
1. Двойной клик: start.bat
   - Это запустит всё и откроет браузер

2. Или вручную:
   - Терминал 1: ollama serve
   - Терминал 2: node server.js
   - Открыть: http://localhost:3001

ВОЗМОЖНОСТИ
-----------
- Чат с AI (без цензуры)
- Голосовой ввод (Chrome/Edge)
- Скриншоты (AI видит ваш экран)
- Работа с файлами (чтение/запись)
- Выполнение команд
- Управление ПК (выключение/перезагрузка)
- Автоматизация браузера (с puppeteer)

ПРОБЛЕМЫ И РЕШЕНИЯ
------------------
В: "Node.js not found"
О: Установите Node.js с https://nodejs.org/

В: "Ollama not responding"
О: Запустите: ollama serve

В: "Model not found"
О: Запустите: ollama pull qwen2.5:7b

В: "Server failed to start"
О: Запустите: node server.js

В: Голосовой ввод не работает
О: Используйте браузер Chrome или Edge

В: Скриншоты не работают
О: Разрешите захват экрана в браузере

ФАЙЛЫ
-----
start.bat              - Запуск программы (двойной клик)
build_installer.bat    - Создать установщик Windows (.exe)
installer.js           - Мастер установки
server.js              - Локальный сервер для системных команд
dist/                  - Собранный веб-интерфейс
INSTALL.md             - Полная инструкция по установке
USAGE.md               - Инструкция по использованию

ПРИВАТНОСТЬ
-----------
- Все данные хранятся локально
- Ollama работает оффлайн
- Нет внешних API
- Нет телеметрии
